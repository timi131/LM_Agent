Агент умеет искать в интернете, работать с файлами, запускать команды, искать по вашим документам и помнить важное между разговорами. Опасные действия он выполняет только после вашего разрешения.

Введите адрес выше или попросите агента сделать что-нибудь на сайте — здесь будет видно каждое его действие.

Можно кликать, печатать и прокручивать прямо здесь — например, чтобы самому войти на сайт.

Факты отсюда агент видит в каждом разговоре. Он добавляет их сам, когда вы о чём-то просите помнить, или их можно добавить вручную.

    По этим файлам агент ищет по смыслу. Подходят .md, .txt, .pdf, .docx, .html, код, а также таблицы .csv и .xlsx — по ним агент умеет считать. Папка:

      В заданное время агент выполнит запрос и пришлёт результат. Задачу можно поставить и словами в чате: «каждое утро в 9 присылай сводку по заявкам».

        Вход в агента
