LM Agent …

Чем помочь?

Агент умеет искать в интернете, работать с файлами, запускать команды, искать по вашим документам и помнить важное между разговорами. Опасные действия он выполняет только после вашего разрешения.

Агент думает…

Факты отсюда агент видит в каждом разговоре. Он добавляет их сам, когда вы о чём-то просите помнить, или их можно добавить вручную.
